# 社区原ZIP网页试玩：接续设计

状态：2026-10-31代码及隔离浏览器回归已完成；真实账号、云端附件及跨账号联机验收未完成。本机使用明确标注的合成导出ZIP检查加载、移动、隔离与关闭，不属于模型成品验收或第05轮通关证据。

## 原则

使用同一帖子已验证的真实ZIP、原GameSpec、runtime-data、素材和引擎，不重新生成地图/图片，不以新版重建结果冒充原导出。帖子仅公开不代表通过质量验收，实验失败状态照常保留；试玩初始化也不能自动标记通关。

## 当前实现与边界

1. 小型manifest API先用调用者RLS检查帖子/ZIP及下载许可；作者/审核人可检查自己/待审作品，公开玩家仅按许可读取。只签发短效URL、字节数、SHA256及受支持原版引擎哈希，不用服务端代理大ZIP，不返回私有存储路径/Key。
2. 浏览器按需下载、限制45MB、校验整包哈希；原makeZip输出是stored method=0，首版可明确只支持此原生格式。压缩/历史不兼容格式保留下载，不偷偷换当前引擎重演。
3. 用Worker做有界ZIP目录/条目/CRC检查，限制512项、合法路径、重复/重叠/越界；停止时终止Worker。项目已支持ATTRIBUTION.txt及精确哈希的内置SVG，不能再次漏掉原导出格式。
4. 执行前校验game.js与明确受支持的Pixel World原版引擎字节哈希相符；未知/修改的脚本拒绝内嵌。首版只支持当前引擎，后续保留经过复核的旧版哈希/实现，不能自动信任任意上传脚本。
5. 不执行原index.html：只从中提取有界runtime-data JSON。用自己控制的HTML壳和安全转义的project.json，保留原地图坐标/关卡数据；只将已校验素材转换为受控Blob URL，禁止远程/路径穿越引用。
6. iframe仅sandbox=allow-scripts，不给same-origin、弹窗、表单或顶层导航。CSP默认none，仅放行随机nonce对应的受信脚本、受控样式及图片/影音Blob，禁止网络连接和嵌套页面。父页面创建的Blob不能直接供不透明源iframe加载：浏览器回归发现这一缺陷后，改为发送经校验的素材字节，在iframe内部创建并回收Blob URL。原ZIP脚本/CSS须匹配固定引擎产物哈希，原HTML不执行；主页面不eval脚本。
7. 仅接收来自该iframe的带随机标识初始化/错误消息，初始化不代表通关。用户点击后才启动，离开/关闭即停止引擎、Worker、下载并回收Blob URL；不改变制作台第05轮原数据。
8. 中英文错误/加载/不兼容提示，失败保留下载入口；卡片区继续显示作者、许可、模型与实验失败/未验证状态。真实验证需浏览器、真实发布附件、网页试玩、关闭清理、无跨账号访问和无外部连接证据。

- 上级目录`creation-language-verification/playback-browser-regression/browser-regression.json`：合成ZIP加载、图片解码、英语界面及角色移动通过；父页面/存储访问及外连受阻；关闭后模拟时间不再推进、拒绝新动画帧、Worker和Blob资源释放，第二次打开关闭也通过。
- 同目录`01-synthetic-preview-running.png`与`02-synthetic-preview-closed.png`；早期失败截图及报告保留。所有记录明确标注合成场景，模型调用为0，未登录/发布真实社区。
- 原生ZIP解析限制stored格式、45MB、512条目，并检查CRC/路径/重叠/整包与引擎哈希；历史不兼容ZIP只能下载，不偷偷替换成当前引擎。
- 固定引擎和CSS产物由`scripts/generate-offline-engine.cjs`生成，生产构建先核对产物与源码一致。更改引擎源码后须重新生成；不能仅手改哈希放行未知脚本。
- 还需：真实云项目迁移、本人及另一账号的发布/读取/撤销权限、实际同轮ZIP网页和离线试玩；当前检查不能替代这些项目。
