# 音游打击感升级使用说明

在世界主页选择节奏音游，写创意→设置玩法→应用并更新试玩→开始演奏。新作品默认新版编排；旧作品保留经典单击，主动选择“音符编排：新版乐句”并应用才升级。

- D/F/J/K 对应四轨；短音符单击，长条持续按住直到尾部，双押同时击打两轨。支持触控、键盘与混合输入。
- Perfect ±45ms，Good ±160ms。长按头尾独立计分；过早松手断连击。空击有扣分和断连击，持续乱按不能刷分。
- 舒缓、标准、挑战三档改变长按、双押与切分密度。BPM60–160，小节4–16，判定偏移-250至250ms。
- 命中提供轨道亮光、粒子、判定文字、早晚毫秒数、独立打击音；双押和十连击有强调。能量、准确率、最大连击和结算等级有真实计数。
- “打击反馈与音量”可分别调视觉强度、打击音量、音乐音量；震动默认关闭。系统减少动态效果偏好关闭粒子和震动。反馈不暂停游戏，也不改变判定。
- 暂停后长按需要重新按住对应轨道；恢复有220ms重抓宽限。音乐静音不停止判定时钟。
- 修改设置后先应用更新试玩，再保存；游戏ZIP取当前试玩版本，项目数据取编辑规格。项目库导入ZIP会建立独立新作品，不覆盖原作品。

本机示例：[星夜回响·打击感升级](http://localhost:3012/?project=custom-eef27f0d-3e3d-4d4d-a427-6525e9836493)。不同浏览器或Vercel环境请导入同名ZIP后继续编辑。

此版仍采用本地规则谱面、程序合成音乐与几何场景，没有付费AI调用、真实歌曲导入或手工谱面编辑。音频调度使用AudioContext时钟；实际设备延迟和主观打击听感需试听校准，未测量端到端延迟。参考：https://www.w3.org/TR/webaudio/ 。

验证：94文件652项自动测试、类型检查和独立生产构建通过；真实浏览器输入完成长按1和双押1，得分565、命中6/55，是输入机制检查，不是全曲通关。实际ZIP导入3012成功，原7份作品保留。ZIP自包含与JSON一致性静态核对；没有冒称物理断网或本地file协议实测。
