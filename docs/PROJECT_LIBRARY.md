# 主页制作与项目库使用说明（2026-11-02 第27批）

本说明替代第24、26批把玩法创建放到项目库的结构。

## 主页负责制作

打开站点首页，在原像素横幅下方的“我要制作”中选择玩法。切换不跳到另一制作网站，原平台动作三栏和画风保留。

| 主页选项 | 当前可制作范围 | 尚未接入 |
| --- | --- | --- |
| 平台动作 | 原GameSpec V3完整流程：故事、策划审核、内置/上传/AI素材、精确地图、物理、机关、角色池、Boss、网页与离线游戏 | 本批不新增2D机制 |
| 节奏音游 | 四轨3D基础模板、程序合成音乐；标题、创意、四种环境、BPM、小节数、判定偏移、布局种子；真实音符判定与计分、演奏结束、保存及ZIP导出 | 外部歌曲、音频上传、自定义谱面、AI编曲与复杂3D模型 |
| 自由探索 | 第一人称方块场景收集模板；四种环境、种子、场景尺寸、景物数量、速度和水晶目标；移动、收集和出口、保存及ZIP导出 | 自由地形、复杂模型、完整场景编辑和任意互动机制 |

音游和探索使用内置规则与几何体，没有接入AI调用；不要把“按创意整理本地模板”称为AI生成。VR代码来自旧原型但本批不展示入口、不承诺头显支持。

### 制作音游或探索

1. 在主页选择玩法，填写标题、创意，选择环境并调整规则。
2. 点击“应用并更新试玩”，右侧加载对应游戏。调整规则不会即时重启正在玩的场景，应用后才更新。
3. 点击游戏内“开始试玩”。音游使用D/F/J/K或四轨按钮；探索使用WASD移动、方向键转向和鼠标拖动。暂停/失焦暂停保留。
4. 点击“保存到项目库”，将可运行规格保存成作品。普通编辑另有各玩法本机草稿，切换玩法时保留。
5. “导出游戏ZIP”：保留玩家标题，解压后打开index.html游玩，不需要模型API和外部素材下载。
6. “导出项目数据”：导出该玩法的JSON，用于重新导入继续编辑，不是独立游戏。

初版音游固定四轨、判定窗口±180ms，偏移支持-250至250ms；BPM60至160、小节数4至16。探索水晶目标3至12、场景尺寸20至48；场景生成与碰撞、收集、出口使用固定模板。

## 项目库负责管理作品

顶部“项目库”进入“我的作品”，不再提供另一套玩法创建流程。这里放：草稿、已保存的游戏作品和归档作品。

- 搜索、按玩法筛选、查看作品状态。
- 修改标题与创意，复制独立项目，归档和恢复。
- “保存并回主页继续编辑”打开该作品的正确玩法；玩法规则在主页调整。
- 导入项目数据或本工具原生游戏ZIP，每次导入新建独立ID，不覆盖原作品。
- 导出完整项目数据；有已保存运行规格的作品可以导出游戏ZIP。
- 老的音游/探索“策划草稿”继续保留，回主页后可以制作成可试玩模板；它们不会自动冒称已制成游戏。

复制、导入、修改只影响对应作品。多页面事务版本校验继续阻止旧页面覆盖新内容。当前项目库仅在本机浏览器保存，没有Supabase项目云同步；localhost不同端口与Vercel之间通过导入导出迁移。

## 数据、导出与验证边界

原2D GameSpec、存储与素材缓存不强制改写。3D沿用受限Spatial V1数据，通过统一项目壳管理。旧原型仅选择性复用规格、播放器与导出，没有整包覆盖主线，没有接入原型的付费AI接口。

网页预览和3D离线包使用同一播放器。预览在无same-origin权限的sandbox iframe运行，导入只解析JSON，绝不执行压缩包中的HTML/JS。社区2D上传校验仍要求原四个运行文件，空间ZIP不能伪装成社区已验证2D游戏；本批未做3D社区发布。

实际验证见留证第27批：主页切换、音游命中计分与演奏结束、探索移动、保存后从项目库重开、实际ZIP/JSON导出与重导入。测试通过不代表完成付费AI三档验收、PICO真机测试或一分钟演示。
## 第28批界面更新
音游与探索现使用和原平台动作相同的三栏组件、卡片、控件、状态提示及像素预览。按写创意→设置玩法→试玩与保存操作，步骤可随时切换。尚未应用的草稿不会重置或替换当前试玩；导出游戏ZIP取当前试玩版本，导出项目数据取当前编辑规格。已保存作品按项目独立恢复未保存草稿、当前步骤和已创建试玩。
