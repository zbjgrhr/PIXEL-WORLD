# 创意工坊与艺术作品：免费服务接入

核对日期：2026-10-31。用户已创建云项目并执行初始化，本机连接项已配置；真实只读访问核实8个社区表、私有45MB存储桶和匿名审核表拒绝，本地预览configured/uploadsConfigured均为true。GitHub登录服务尚未启用、没有登录会话，真实双账号权限、上传和公开发布仍未验收。证据见上级creation-language-verification/supabase-cloud-initialization-check.json。

## 第一阶段方案

建议先用 Supabase Free 统一提供身份认证、Postgres 数据库及文件存储，避免一开始同时配置多个服务。官方免费额度包括 500 MB 数据库、1 GB 文件存储、每月 5 GB 非缓存流量与 5 GB 缓存流量、50,000 月活跃用户。免费项目一周不活跃可能暂停；单文件最多 50 MB。

来源：
- https://supabase.com/pricing
- https://supabase.com/docs/guides/storage/uploads/file-limits

项目先将社区单文件限制为 45,000,000 字节，上传前明确提示。这个限制不影响本地游戏导出，也不会静默删素材压到限制以内。容量和流量接近额度时需提示并停止新增上传，不自动开通付费套餐。具体云端配额检查仍待接入实现。

若真实视频或游戏 ZIP 经常超过单文件限制，后续可采用 Supabase 登录/数据库 + Cloudflare R2 Standard 存大文件。R2 有每月 10 GB-month 标准存储、100 万 A 类和 1000 万 B 类操作免费额度，直接下载无流量费；超出免费额度仍会计费，不能宣称永久免费或没有账单。

来源：https://developers.cloudflare.com/r2/pricing/

## 用户先做的步骤

1. 打开 https://supabase.com/dashboard 注册或登录自己的账号。
2. 创建 Free 组织和名为 pixel-world 的项目，不选择付费套餐。数据库密码自行保存，不发到聊天。
3. 项目建立完成后告知 Codex；下一步再核对项目连接信息并安排本地配置。不要发送账号密码、数据库密码或服务端管理 Key。

本阶段不要求用户开通 R2 或绑定付费条件。基础设施费用与模型每轮 USD 2 验收预算分别记录。

## 已准备的代码

### ZIP导出与上传兼容

上传检查接受原导出四个根文件及可选ATTRIBUTION.txt，并继续检查文本脱敏、CRC、路径/重复项和展开大小。内置素材使用SVG：configs/builtin-svg-registry.json固定25份项目自带原图的SHA-256，已静态检查仅包含svg/path及几何、颜色和透明度属性。ZIP中的SVG必须精确匹配该清单；普通图片上传仍不支持SVG。

位图条目检查PNG/JPEG/GIF/WebP文件头，拒绝未知SVG改名伪装；历史误命名为PNG的内置SVG仅在哈希精确匹配时兼容。导出现在按SVG内容类型使用.svg扩展名。更新内置原图后需复核并更新清单，不能把任意SVG加入白名单。ZIP结构/文件头检查不等于成品质量或实际通关验收。

### 模板质量复核（第010号迁移）

GET /api/community/templates?language=zh-CN（或en）提供独立精选列表。可信候选函数只返回已公开、允许改编且最新审核仍通过、版本一致的作品ID；调用者RLS再次检查公开状态，随后有界批量核对记录、四项复核和同轮已验证附件。最新决定若拒绝，不能回退到旧通过；帖子变动/许可收回也使旧入选失效。不使用“最近20篇普通帖子”先过滤，避免合格旧作品被新实验挤走。

创意工坊抽屉将“已复核成品模板”与“示例设定”分开。成品卡片保留作者、语言、文字/图片模型和补齐数量/比例，提供原帖实际媒体预览与下载入口，不伪造效果图。未配置服务、查询失败和没有该语言成品分别提示。当前没有真实入选作品，实际云端/跨账号展示未验收；成品两种复用代码已接通，内嵌试玩尚未接通。

成品卡片的“只用故事/沿用完整设定”先确认替换当前输入，再调用GET /api/community/templates/[id]/reuse核对当前入选、许可、语言、版本和唯一GameSpec。下载实际文件后核对字节数/SHA-256，再复查是否发生撤销或版本变化。两种方式保留来源署名；完整方式保留策划参数、清除全部旧图与帧条，初始素材为待制作。不会复制批准、启动Agent或触发付费生成。

原始署名链、作者和许可保存在GameSpec.templateSources；随草稿会话、更新、迁移与离线导出保留。离线页与ATTRIBUTION.txt展示署名。读取期间修改当前输入/语言、关闭工坊或启动任务时，不应用过期结果；失败保留原输入。超过10关、512,000字节导入结果、多份未指定主本的GameSpec等当前不支持的情况会明确拒绝，不截断或猜测。真实界面点击及新作品完整重审尚未联机验收。

帖子公开与优秀模板入选分开。具备审核权限的账号在已公开、关联实验的工坊作品卡片看到“审核是否入选模板”。需要实际检查附件、下载核对GameSpec/ZIP，分别填写故事忠实度、素材质量、网页通关和离线通关结论及证据ID，再明确确认。作者自报通过不能代替这次复核。

POST /api/community/posts/[id]/template-review再次检查同源、会话、审核角色；数据库函数复核角色和帖子版本，并要求已完成、已公开、允许署名改编、同作者同轮已验证附件、GameSpec、ZIP、可靠时长不超过60秒的演示及无未解决阻断/严重问题。四项必须有同轮证据。普通作者不能直接写审核表。

审核记录追加保存；后来“暂不入选”不会删除旧审核，也不会把公开帖子下架。模板审核表仅审核角色/服务端可读。公开列表与复用接口均检查最新审核与帖子修订失效。保存审核决定不等于真实云端已展示或已真实通关。第010号迁移未在真实云端执行，没有作品入选。

### 作者昵称与头像（第009号迁移）

真实账号登录后，社区工具栏提供“作者资料 / Author Profile”。昵称、头像和作品署名绑定会话账号，不接受浏览器指定作者，也不根据“【IA】”等昵称授予官方身份。官方标记只由项目管理员按真实身份分配。

本版头像选择复用现有已验证上传：先保存自己的艺术作品草稿，通过“添加附件”上传静态头像，再到作者资料选择该文件。当前显示最近100张合格图片，单张不超过5,000,000字节、单边不超过4096像素且只有一帧；没有独立头像文件直传入口。后续可优化这一操作，不能称为已实现单步头像上传。

选择新头像须确认公开裁剪缩略图。头像接口仅按公开资料中已选文件读取本人已验证原图，核对实际字节与SHA-256，解码/裁剪成256像素WebP并移除原始元数据；不返回原文件、存储路径或签名源地址。原文件仍受原有帖子/下载权限保护。缩略图浏览器缓存60秒，移除后不承诺立即撤回已缓存或已保存的图像。

昵称与头像使用版本校验保存；过期或网络结果不明时先重新加载，不自动重试。文件清理与头像选择锁定相同媒体记录，正在使用的头像需先移除才能删除；删除帖子仍保留原文件与资料头像。未配置服务时资料接口503、头像404，不虚构账号或保存成功。真实云端迁移、双账号复测和【IA】头像发布均未执行。

- /community：中英文玩家社区入口，区分游戏实验与艺术作品；未配置后端时明确显示未接入，不模拟登录或公开帖子。
- lib/supabase/、middleware.ts、app/auth/callback/：GitHub 登录的浏览器客户端、服务端会话和回调基础。
- app/api/community/：从服务端验证身份，读取公开帖子或本人草稿，保存、编辑、删除并提交自己的帖子；修改公开内容后重新审核，过期版本拒绝覆盖或删除。删除帖子保留原游戏和素材文件。附件上传、实验记录导入与详情代码已连接，真实联机流程未验收。
- app/api/community/reports/：举报已公开帖子、查看本人举报状态；服务器绑定举报人，同一账号同一帖子仅能提交一次。普通用户不能读取其他人的举报或改处理状态；数据库策略同样阻止猜测私有帖子 ID 进行举报。处理入口见 /community/moderation。
- supabase/migrations/202610310001_community.sql：所有权、草稿/待审/公开状态、私有附件、举报及审核权限。普通玩家不能自授管理员身份或自行标记审核通过。
- supabase/migrations/202610310002_community_review.sql：版本校验后的提交审核、审核决定与操作记录同一事务保存、内容下架和举报处理。附加数据库触发器同样阻止直接发布无媒体的艺术帖子或关联不同语言的实验。
- /community/moderation：有审核权限的真实账号可审核文字帖子、查看图片/视频/音频、下载检查 ZIP/规格/报告、下架问题内容和处理举报。通过前必须明确确认内容与全部附件；附件清单在服务端再次核对，未验证或未确认检查的附件不能直接通过。
- /api/community/posts/[id]/media：先验证调用者能否访问帖子，再查看关联附件；不会通过一个公开帖子的 ID 访问另一篇私有帖子的文件。元信息不暴露存储路径，实际预览按需签发 300 秒链接，使用调用者身份和数据库/存储策略，不用管理 Key 绕过权限。
- lib/community-database.test.ts：在本机 PostgreSQL 兼容运行时执行迁移，验证跨账号修改、附件和审核权限；这不等于真实 Supabase 登录/存储联机验收。

- lib/community-types.ts：区分作品帖子、实验记录、媒体文件、作品语言、模型配置、耗时/费用、补齐来源、问题、验收证据和模板审核。
- lib/community-validation.ts：草稿作者绑定服务端会话身份；拥有者校验；上传元信息预检；已上传附件/运行/语言关联检查；常见凭证文本检查；优秀模板证据门槛。
- lib/community-validation.test.ts：覆盖冒用作者、绕过草稿状态、跨轮附件、未上传本机文件、失败实验、格式/大小和缺少通关证据。
- lib/community-file-inspection.server.ts：准备实际字节校验与 SHA-256；图片解码、动画基本元数据、影音容器/轨道/时长、GameSpec 基础结构与报告脱敏检查。影音没有逐帧解码，不能把解析成功当作全片可播放或质量合格。
- lib/community-archive.server.ts：游戏 ZIP 在内存中逐项解压检查大小与 CRC，拒绝路径穿越、重复文件、链接、加密条目及不支持的可执行格式，检查项目规格；不运行 HTML/JavaScript，不证明关卡可通关，也不是恶意代码扫描器。
- scripts/inspect-community-file.ts：本机检查现有文件，输出文件名、哈希和元信息，不上传、发布、执行游戏或调用模型。历史第 01 轮 GIF 和第 03 轮 ZIP 的检查结果保存在上级 creation-language-verification/ 中。

这些函数不是完整的上传安全实现：服务端还需实际检查文件字节、验证会话与数据库权限、核对哈希、限流/额度、完成审核和删除流程。常见凭证模式检查不能代替人工脱敏。文件还未上传时，不能靠本机路径或任意 verifiedAt 字段冒充已发布附件；该字段将由服务端上传验证流程维护。

文件检查函数已接到服务端上传校验与可信入库接口，浏览器上传界面已连接；真实 Supabase 联机尚未验收，不能据此标记云端文件已验证。当前检查上限：文件 45,000,000 字节；图片单页 32,000,000 像素、尺寸各不超过 8192，动画最多 1000 帧且总像素不超过 160,000,000（抽查首末页解码）；影音不超过一小时并要求有效轨道/时长。ZIP 为 Pixel World 导出结构，最多 512 个条目、解压总量 150,000,000 字节。超限文件保留本地原件，社区上传需明确告知限制，不修改本地导出能力。

报告支持 UTF-8 Markdown、TXT、LOG。失败的原始模型输出若不是有效 GameSpec，可在保留原始文件的同时整理为脱敏报告，不能冒称有效规格。模板演示允许已验证的 MP4/视频，或有可靠时长信息的动画 GIF/WebP；静态图、未知时长或超过 60 秒仍不满足演示门槛。

实现参考：https://github.com/Borewit/music-metadata 、https://github.com/thejoshwolfe/yauzl 、https://sharp.pixelplumbing.com/api-input/ 。库能读取格式与元数据，不代表内容已完成安全、版权或成品质量审核。

## 项目创建后的配置步骤

1. 在自己的 Supabase 项目 SQL Editor 中按编号顺序执行supabase/migrations中的001至010共10份迁移（包括009资料头像、010精选模板）。桌面PixelWorld-社区初始化.sql已将这10份合并为一个事务，限本次新空项目一次执行；两种方式不要混用或重复执行。已有业务库应先核对迁移记录，不盲目初始化。
2. 依照仓库 .env.example，在本机 .env.local 设置 NEXT_PUBLIC_SUPABASE_URL 与 NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY。只使用 publishable 或旧版 anon 公钥，不能填写 secret 或 service_role。实际文件不要提交 Git。
3. 在 Supabase Authentication → Providers 启用 GitHub。GitHub OAuth App 的回调地址填写 Supabase 提供的 https://项目标识.supabase.co/auth/v1/callback。GitHub Client Secret 只填入 Supabase 控制台。
4. Supabase Authentication 的 Redirect URLs 允许本机 http://127.0.0.1:3005/auth/callback（使用 localhost 时也添加对应地址），以及实际部署域名的 /auth/callback。Site URL 设置为正式网站地址。不要混淆这一步与 GitHub 应用回调。
5. 重启预览后，从 /community 验证登录和草稿保存。Vercel 的公开环境变量也需要单独配置并重新部署；本阶段不自动推送或部署。
6. 首个审核账号必须由项目所有者在 SQL Editor 将其真实 auth.users.id 加入 community_moderators。显示名、头像和用户自行填写的 metadata 均不会授予此权限；本阶段没有自动创建或指定审核账号。

参考：https://supabase.com/docs/guides/auth/social-sign-in/auth-github

## 上传服务端接入进度

服务端另需本机环境变量 SUPABASE_SECRET_KEY（现代 secret 或旧版 service_role）。只能由服务端读取，不能使用 NEXT_PUBLIC 前缀，不能填写到网页模型 Key 框。缺少此配置时仍可使用文字社区入口，但上传接口明确返回未配置。当前没有保存任何实际凭证或创建云项目。

- POST /api/community/uploads：确认登录者拥有目标草稿，预留文件名、类型、存储路径与容量；浏览器不能指定作者或验证状态。
- 浏览器使用自己的登录会话向私有存储上传到已预留路径，不能覆盖其他对象。上传界面已连接，不开放任意路径上传。玩家保存草稿后，在本人草稿卡片选择“添加附件”；“管理上传”可查看记录并显式清理未完成任务。中英文均有状态说明。
- POST /api/community/uploads/[id]：服务端读取实际文件，核对字节数、类型、SHA-256 和内容规则；可信媒体记录、帖子附件关系及上传回执在同一事务保存。响应丢失后先核对回执，避免重复入库。
- DELETE /api/community/uploads/[id]：显式清理未关联文件；先停止继续上传，再删存储对象，确认对象消失后释放容量。删除帖子不会顺带删除原素材。
- 当前应用内限制为每人 300,000,000 字节、全站 850,000,000 字节，同时最多 2 项待完成上传。每项待完成任务预留完整单文件上限，过期任务仍计入，直到确认清理，防止低报大小或过期绕过容量。

上述是本应用管理文件的容量计数，不包含同一 Supabase 项目被其他工具写入的文件，也不监控真实月流量或数据库大小。界面显示传输进度并单独说明校验阶段；传输最多等待 120 秒，失败不自动重试，保留记录供手动检查/清理。当前采用单次标准上传，尚未实现大文件断点续传。云端使用量告警、实际双账号及网络中断测试仍待完成。不能将本机数据库/模拟存储测试写成真实上传通过。

现阶段已实现文字草稿保存、本人帖子编辑/删除/提交审核、图片/影音预览、附件确认审核、举报处理、服务端上传校验接口、浏览器上传入口及 ZIP/规格/报告下载复核入口。实验导入与真实双账号联机验收仍在任务清单中，不能把现有检查写成社区功能全部完成。

## 下载与复用授权

作者在草稿中选择“仅展示”“允许下载”或“署名后可改编”，界面展示授权范围。默认仅展示，不自动扩大授权。

- ZIP、GameSpec、报告只有作者、真实审核人，或获公开下载授权的访客才能取得下载链接。只有帖子已公开且授权允许下载，访客才能下载；数据库存储策略同样限制直接 Storage SDK 读取，不能绕过网页按钮。
- 图片、视频和音频仍按帖子可见性提供预览。“仅展示”是使用许可，不是阻止另存或录屏的技术保证；不能宣称已展示内容无法复制。
- 下载链接按需生成，300 秒过期，强制使用附件下载文件名；压缩包、脚本、报告不会在页面自动执行。授权撤销或下架阻止新链接，已签发链接可能继续有效到过期。
- 审核人必须自行下载检查 ZIP、规格和报告，点击链接或服务器校验通过都不算完成内容复核。界面逐附件确认，最终批准核对完整附件集合。下载检查不自动标记游戏已通关或已入选模板。
- 同一文件若被作者放到另一篇允许下载的公开帖子，存储对象也已获得那篇帖子的公开下载授权。帖子授权不是对同一文件的不同副本施加数字版权控制。

## 撤回草稿与修改附件

本人待审、已公开或被退回的帖子，可以明确选择“转为草稿”。操作要求当前版本匹配，并撤回公开/待审状态；文字、原附件与文件保留。旧的审核决定不能批准已撤回的新版本，再次公开需重新提交审核。

在本人草稿的附件区域，可以选择“移除附件”，仅解除本帖子关联。若文件已无任何帖子关联，会出现在上传管理的保留文件中，玩家可另行确认清理；不能把移除附件写成已删除原文件或释放存储。没有媒体的艺术草稿仍可保存，但不能提交审核。

新增关联与清理文件使用数据库锁和状态校验：文件已进入删除过程时不能重新加入帖子，待审/公开帖子不能直接替换附件。接口不使用浏览器传来的作者或存储路径，过期版本和其他玩家的帖子一律拒绝。

上述流程已通过接口和本机数据库检查，真实账号的撤回、附件替换、重新提交及云端文件保留尚待联机验证。

预览组件展开后才获取媒体，不自动播放影音；加载失败可手动刷新，不记为已查看。审核人还需要实际观看/播放并确认，加载成功不等于画面质量合格。帖子下架后无法获取新的公开预览链接，但此前已签发的链接可能继续有效到其 300 秒期限；浏览器已经取得的内容无法追回。链接不得作为永久附件地址保存到模板或导出作品中。
